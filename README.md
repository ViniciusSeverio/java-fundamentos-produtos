# ☕ Java Fundamentos — Produtos e Formatação

Exercício desenvolvido durante meus estudos de **Java**, com foco nos fundamentos da linguagem, declaração de variáveis e formatação de informações no console.

## 🎯 Objetivo

Praticar a utilização de diferentes tipos de dados em Java e apresentar informações utilizando saída formatada com `printf()`.

## 📚 Conceitos praticados

* `String`
* `int`
* `char`
* `double`
* Declaração de variáveis
* `System.out.println()`
* `System.out.printf()`
* Especificadores de formatação
* Casas decimais
* `Locale`

## 💻 Funcionamento

O programa trabalha com informações de produtos e outros dados básicos, como:

* Nome do produto
* Preço
* Idade
* Código
* Gênero
* Medida

Os valores são apresentados no console utilizando diferentes formatos.

### Exemplo de saída

```text
PRODUCTS:
Computer, which price is R$ 2100.00
Office desk, which price is R$ 650.50

RECORD: 23 years old, code 7777 and gender: M

Measure with eight decimal places: 53,23456700
Rounded (three decimal places): 53,235
US decimal point: 53.235
```
